# Acesso pelo celular

O Rony pode ser acessado pelo celular quando o computador e o telefone estao na mesma rede Wi-Fi.

1. Abra o Rony no computador.
2. Clique no botao `celular` na interface.
3. Abra no telefone o endereco exibido, no formato `http://IP-DO-PC:5173`.

O aplicativo tenta liberar automaticamente as portas locais `5173` e `8765` no Firewall do Windows. Se o Windows pedir permissao de rede, permita o acesso em rede privada.
